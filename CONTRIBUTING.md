# Contributing to Burrow

Thank you for your interest in Burrow!

## Current Contribution Policy

> **Important**: External code contributions and pull requests are **NOT** currently accepted.

Burrow is currently developed and maintained directly by the core team. At this stage of development, we do not accept unsolicited code contributions or pull requests from external contributors. Any pull requests opened by external contributors will be closed without review.

## Future Contributions & Contributor License Agreement (CLA)

When external code contributions and community pull requests open in the future, all contributors will be required to sign our [Contributor License Agreement (CLA)](CLA.md) before any contribution can be accepted or merged into the codebase.

The CLA protects both contributors and the project by ensuring that:
1. Contributors retain copyright in their original work while granting Burrow the necessary licenses to distribute, sublicense, relicense, and commercialize the software (critical for Burrow's dual-license and open-core model).
2. The project has clear patent grant protections.
3. Contributions are original works or appropriately authorized by employers where applicable.

Please review [CLA.md](CLA.md) for full terms and conditions.

## Bug Reports & Feature Discussions

While we do not accept pull requests at this time, feedback from users is welcome and appreciated:
- **Bug Reports**: If you discover a bug, unexpected behavior, or security issue, please open an issue on GitHub with reproduction steps, environment details, and expected vs. actual behavior.
- **Feature Requests & Ideas**: Open an issue or start a discussion on GitHub to suggest enhancements or workflow improvements.

Thank you for your understanding and support as Burrow continues to develop!
